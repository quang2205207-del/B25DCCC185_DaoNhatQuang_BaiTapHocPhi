Repository gồm 4 bài Java về quản lý sinh viên và học phí.

- **Họ và tên:** Đào Nhật Quang

## Yêu cầu

- Java JDK 8 trở lên
- Terminal hoặc Command Prompt

Kiểm tra Java đã cài đặt:

```bash
java -version
javac -version
```

## Cách tải repository

```bash
git clone https://github.com/quang2205207-del/B25DCCC185_DaoNhatQuang_BaiTapHocPhi.git
cd B25DCCC185_DaoNhatQuang_BaiTapHocPhi
```

## Cách biên dịch và chạy từng bài

Mỗi thư mục `Cau1`, `Cau2`, `Cau3`, `Cau4` đều là một chương trình Java độc lập với file `Main.java`.

### Câu 1

```bash
javac Cau1/Main.java
java -cp . Cau1.Main
```

### Câu 2

```bash
javac Cau2/Main.java
java -cp . Cau2.Main
```

### Câu 3

```bash
javac Cau3/Main.java
java -cp . Cau3.Main
```

### Câu 4

```bash
javac Cau4/Main.java
java -cp . Cau4.Main
```

Sau khi chạy, chương trình sẽ chờ dữ liệu nhập trực tiếp từ bàn phím.

## Chạy bằng một lệnh (Linux/macOS/Git Bash)

```bash
javac Cau1/Main.java && java -cp . Cau1.Main
javac Cau2/Main.java && java -cp . Cau2.Main
javac Cau3/Main.java && java -cp . Cau3.Main
javac Cau4/Main.java && java -cp . Cau4.Main
```

## Chạy trên Windows

Mở thư mục của từng bài trong VS Code hoặc Command Prompt, sau đó thực hiện:

```cmd
cd Cau1
javac Main.java
java Main
```

Tương tự, thay `Cau1` bằng `Cau2`, `Cau3` hoặc `Cau4` để chạy các bài khác.
